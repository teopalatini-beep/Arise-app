# Coach — page override

> Overrides `design-system/arise/MASTER.md` for the Coach tab.

**Vibe:** Dark Luxury command center (Aston-glass + gold accent refs).  
**Not:** anime, purple neon, emoji mascots.

## Layout

1. Ambient charcoal gradient background (`GRADIENTS.background` / gold wash mesh).
2. Compact identity header: monogram orb + coach name + status line (not a busy dashboard).
3. Message list with generous breathing room; one primary composer at bottom.
4. Single primary CTA: send (gold filled, dark ink).

## Surfaces

- Bubbles / composer: glass + hairline gold border (`METAL.goldBorder`).
- User messages: gold fill + `INK.inverse` text.
- Coach messages: elevated charcoal + soft gold edge.

## Motion

- Enter: fade + slight translate (150–260ms), respect reduced motion.
- Press: scale ~0.97 on send / chips.
- No decorative particle spam on this screen.

## Copy tone

Direct, high-performance coaching voice. Short paragraphs. No slang anime.
